# LokiCheckout_LumaSkinny

**This is an add-on package to the LokiCheckout. It tries to remove as much from the Luma Theme as possible without breaking
the checkout. Instead of using this module, you might also just copy changes from this module to your own custom theme, to
allow for better control over what is removed and what is not.**

## Installation
Install this package via composer (assuming you have setup the `composer.yireo.com` repository correctly already):
```bash
composer require loki-checkout/magento2-luma-skinny
```

Next, enable this module:
```bash
bin/magento module:enable LokiCheckout_LumaSkinny
```
